Privacy Policy

FrostCal is a static reference site. It has no user accounts, no forms, and does not itself set cookies or collect personal information.

What this site collects

Nothing directly. Every page is a pre-built static file; there is no login, comment system, newsletter, or tracking script operated by FrostCal.

Hosting

This site is served by GitHub Pages. Like most web hosts, GitHub may log basic technical information about visits (such as IP address and user agent) for security and operational purposes. See GitHub's privacy statement for details.

Analytics

If analytics are enabled, FrostCal uses a privacy-focused, cookie-free analytics service that records aggregate page-view counts only (no cross-site tracking, no advertising profiles, no personal identifiers stored by us).

Advertising

FrostCal may display third-party advertising (for example, Google AdSense) to keep the site free. Ad providers may use cookies or similar technologies to serve and measure ads, including personalized ads where permitted. You can learn about Google's use of advertising data and opt out of personalization at policies.google.com/technologies/ads. This section applies only if and when ads are actually shown on the site.

External links

Pages link to external resources (NOAA, GeoNames, retailers, and others). Their privacy practices are their own; this policy covers only FrostCal.
